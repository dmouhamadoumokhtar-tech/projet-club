# Club Scientifique LMDB (CSLMDB)

Plateforme web officielle du **Club Scientifique du Lycée Maba Diakhou Bâ (CSLMDB)**.

- **Site en ligne** : [https://cslmdb.up.railway.app/](https://cslmdb.up.railway.app/)
- **Espace administration** : [https://cslmdb.up.railway.app/admin/connexion.php](https://cslmdb.up.railway.app/admin/connexion.php)

## Stack technique
- **Backend** : PHP 8.2 (`mysqli`)
- **Base de données** : MySQL 8 (`sauvegarde.sql`)
- **Frontend** : Bootstrap 5, Swiper.js, Fancybox, Canvas 3D
- **Déploiement** : Docker / Railway
